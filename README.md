Neutral Software is an independent software company focused on high-performance graphics, game-engine technology, systems software, and developer tools.

We build software close to the hardware, with an emphasis on performance, clean architecture, physical accuracy, and giving developers direct control over the systems they use.

## Projects

### Atlas Engine

[Atlas](https://atlasengine.org) is our open-source, cross-platform game engine for modern real-time and offline rendering.

Its technology includes:

- Physically based rendering
- Spectral path tracing
- Vulkan, Metal, and OpenGL graphics backends
- Ray tracing and global illumination
- Physics and simulation
- TypeScript scripting
- Cross-platform editor and tooling

**Repository:** [neutral-software/atlas](https://github.com/neutral-software/atlas)

### Opal

Opal is the low-level graphics abstraction used by Atlas.

It provides a unified interface over modern graphics APIs while keeping explicit GPU concepts visible rather than hiding them behind a large abstraction layer.

### Photon

Photon is Atlas's physically based spectral path tracer.

It is designed to model light using wavelength-dependent transport, supporting effects such as dispersion, participating media, physically based transmission, and caustics.

### Bezel

Bezel is the physics layer used by Atlas, built around high-performance rigid-body and simulation technology.
